## Proof corruption tests

`invalid_sirs_widened_borrow.sirs` widens a nested field borrow from region 2 to region 1. It is rejected with the verifier rule that field borrows must use the shortest lexical/owner lifetime.

`invalid_sirc_missing_transfer_discharge.sirc` changes a successful resource-return edge from transfer discharge to ordinary non-transfer state. It is rejected because the returned resource lacks a transfer discharge.
